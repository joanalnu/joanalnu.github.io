In quantum mechanics, physical states are represented by rays in a complex Hilbert space $\mathcal{H}$ over $\C$. The dynamic evolution and measurement outcomes rely on self-adjoint operators acting on this space.

Postulate 1 Quantum State Space
To every isolated physical system there corresponds a complex Hilbert space $\mathcal{H}$. The state of the system is completely described by a unit vector $\ket{\psi} \in \mathcal{H}$.

Computational Implementation

To simulate this, we can define a basic state vector array using numpy.array() in Python. The transition probabilities between states $\ket{\psi}$ and $\ket{\phi}$ are calculated accordingly.

import numpy as np

def compute_probability(phi, psi):
    """
    Computes the transition probability ||^2
    """
    inner_product = np.vdot(phi, psi)
    probability = np.abs(inner_product)**2
    return probability

# Define two quantum states
psi = np.array([1, 0])
phi = np.array([1/np.sqrt(2), 1/np.sqrt(2)])

print(f"Probability: {compute_probability(phi, psi):.3f}")
